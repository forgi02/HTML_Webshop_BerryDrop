# Berry-Drop-Shop

Berry-Drop-Shop ist ein statischer Schmuck-Webshop mit HTML, CSS und Vanilla JavaScript. Die Seite zeigt eine Startseite mit Produktkarten, eine generische Produktdetailseite, ein Kontaktformular und ein Impressum. Deutsch und Englisch lassen sich per URL-Parameter umschalten.

## Nutzung

1. Öffne `index.html` im Browser.
2. Wechsle über den Sprachlink in der Navigation zwischen Deutsch und Englisch.
3. Öffne ein Produkt über die Startseite, um die Detailseite anzuzeigen.
4. Nutze `contact.html`, um Anfragen zu senden. Wenn du von einer Produktseite kommst, wird der Produkt-Slug im Formular übernommen.

Die wichtigsten Einstiegspunkte sind:

- `index.html`
- `product.html?product=raspberry-pearlette-necklace`
- `contact.html`
- `imprint.html`

## Quellen

- Projektanforderungen und Doku: Inhalte aus `docs/requirements.md`, `docs/data.md`, `docs/visual-design.md` und `docs/journal.md`.
- Produktdaten und Bildpfade: bereitgestellte Dateien in `data/` und `data/data_raw.md`.
- Kontaktformular: Formspree über `https://formspree.io/f/mvzvjwyg`.
- Impressum: Basistext erstellt mit dem AdSimple Impressum Generator; deutsche Version in `imprint.html` übernommen.
